| 前端 | 用发版前的 `index.html` 覆盖 `xs/index.html`，并删掉 `xs/js/admin-workbench.js`、`xs/js/chart.umd.min.js` | 旧 `index.html` 不引用这两个文件 |
| 后端 | `cp /home/xiaos/eggworld/eggworld.jar.bak eggworld.jar && systemctl restart eggworld` | — |
| 数据库 | **不需要回滚** | `page_views` 是全新独立表，旧 jar 既不读也不写；留着只是不再产生新数据 |

> 旧 jar + 新表结构、新 jar + 缺表，两种情况都不会 500：`page_views` 只被新接口访问，而新接口在旧前端下不会被调用。

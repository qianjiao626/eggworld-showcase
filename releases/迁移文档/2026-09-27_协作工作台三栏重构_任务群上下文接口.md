## 一、本次范围

本次把「聊天室」从「实验室.beta 里的二级子页面」重构成**铺满工作区的三栏协作工作台**（左「会话流」/ 中「协同终端」/ 右「任务协作合约」），并补上右栏所依赖的**任务上下文接口**；同分支上一批「任务群交互与认领漏斗重构」的前端改动一并随本次上线（见关联文档）。

1. **结构精简与铺满（§1）**：彻底移除 `#page-lab` 内的二级侧边栏（原 `.lab-shell / .lab-list / .lab-panel`）与**顶部面包屑行**，外壳从工作区最上沿开始、直接铺满（三栏 310px / `flex:1` / 280px）；页面名由「实验室.beta」改为「协作工作台」（侧栏、底栏短标签同步）。
2. **双态收纳（§2）**：废弃原来「全部 / 私聊 / 群聊 / 频道」4 个标签，收拢为 `活跃会话 / 归档库` 两档；**切分类只换列表视图，绝不自动打开或选中第一个会话**，手机上切分类必定停在列表层。归档库判据 = 会话 `readOnly=1` 且是任务群（只读公告频道不算「已结案」，仍留在活跃会话）。
3. **列表零跳动（§3）**：排序键**冻结在客户端**（`orderAt`，只增不减）——纯点击/已读不改键，顺序与滚动位置原地不动；只有真收到/发出新消息才把该会话推上去；重建列表时还原 `scrollTop`（原来 `replaceChildren()` 会把滚动位置归零，是「点一下列表就跳」的根因）。
4. **全中文零 Emoji（§4）**：界面不再出现任何 Emoji；状态词统一为 `进行中 / 待确认 / 已归档`，分类小标为 `教学 / 组队 / 悬赏 / 求助 / 频道 / 私聊 / 归档`，协作者角色为 `导师 / 发布方`（字标「发」）、`学员 / 认领方`（字标「认」），合约数据为 `托管报酬: XX.XX 蛋蛋币` + `周期状态: 履约中 / 验收中 / 已结束`。
5. **任务状态机与二次确认（§5）**：右栏按当前登录用户身份渲染操作按钮 —— 认领方「提交任务成果」（绿，弹确认）、发布方「验收通过并划拨资金」（薄荷，弹**橙底警告**：资金即时结算、群聊转只读并移入归档库）；归档后中栏输入区替换为锁定说明，只读会话不再提示「发第一条消息」。
6. **移动端推拉（§6）**：≤768px 列表 ⇄ 终端左右推拉；聊天区注入 `touchmove`（`{passive:false}`），横向右滑时 `preventDefault()` 截断浏览器前进/后退手势，位移超阈值平滑退回列表。
7. **配色跟随主站（§7）**：聊天室不再维护独立冷灰蓝色板，全部改为引用主站 `:root` 既有令牌（奶油暖底 / 白卡片 / 藏青墨色 / 薄荷主操作），两侧栏用更深一档暖底 + 强分隔线，三栏分区明确；变量仍只声明在 `.chatroom-shell / .chatroom-modal / .chat-admin-grid` 上，**不写 `:root`**。
8. **后端新增任务上下文接口（§8）**：`GET /api/chat/conversations/{id}/context` 一次返回「会话基础信息 + 关联任务 + 成员任务角色」，供右栏渲染；只对会话成员开放（`requireMember`），无关联任务时 `task` 为 `null`。前端按需拉取并缓存（每个任务群只拉一次，用于列表分类小标与右栏）。

要解决的用户问题：聊天室布局冗余（二级夹层）、会话列表点击跳动、分类繁琐凌乱、界面带 Emoji 与模板感、配色与主站不搭；以及右栏缺少可用的任务/成员数据来源。

## 七、备注 / 已知边界

1. **jar 必须与前端同批上线**：本次右栏依赖新增的 `GET /api/chat/conversations/{id}/context`。⚠️ 上一批文档写的「后端无改动、包内不应有 jar」是**当时**的判断，本次已不适用（上一批的上下文接口与其前端一起并入本次上线），**本次包内必须有 jar**。
2. **列表顺序冻结在客户端**（`orderAt`，只增不减）：这是「我只是选中、不要动顺序」的实现方式 —— 点击/已读/切分类都不改排序键，只有服务端时间变大或本地收到/发出新消息才会把该会话提前。副作用：本页会话的相对次序在**首次加载时定下**，之后即使服务端并列项（无消息的群 `lastMessageAt=null`）次序变化也不跟随；刷新页面会按当次服务端顺序重新定序。
3. **分类小标需要按需拉一次 context**：会话列表接口不含任务类型，前端对「任务群」按会话各拉一次 context 并缓存（仅首次），拉到前小标显示中性的「群聊」，拉到后就地替换（不重建 DOM、不重排）。
4. **归档库判据是 `readOnly=1 且 type=group`**：只读公告频道（`type=channel, read_only=1`）不算「已结案」，留在活跃会话里，其锁定文案走「只有频道管理员可以继续发布」。
5. **零 Emoji 是本次的硬约定**：界面文案、状态、按钮一律中文，状态点用 CSS 画（呼吸动画在 `prefers-reduced-motion` 下关闭）。注释里仍保留仓库既有的 `⚠️` 标记，不会渲染到界面。
6. **配色不再自建色板**：`js/chatroom.css` 只引用主站 `:root` 令牌（带兜底值），主站换肤时工作台自动跟随；**不允许在 chatroom.css 里写 `:root`**（主站已有同名 `--primary/--ink/--muted`，覆盖会波及全站），该约束有契约测试钉住。

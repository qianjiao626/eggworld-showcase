## 三、数据库变更

脚本：`backend/sql/migrate-career-test.sql` → `/home/xiaos/eggworld/sql/migrate-career-test.sql`。
内容：仅 `CREATE TABLE IF NOT EXISTS career_test_reports`（用户/答案/报告 HTML/消耗/时间 + 索引）。**无 ALTER / DROP / TRUNCATE；不改存量数据、不动任何资金流水。** 可重复执行（`IF NOT EXISTS`）。

生产操作必须单独授权。普通用户 `xiaos`（**禁止 `sudo`**）先备份并验证可读：

```sh
mkdir -p ~/eggworld/backup/db
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3          # 属主必须 xiaos、大小非 0
head -1 ~/eggworld/backup/db/<本次 dump 文件名> # 能读出内容才算有效备份，读不回来就暂停
```

上传脚本后先比对 sha256，确认非旧文件且备份可读，再仅执行一次；**先建表、再切 jar**：

```sh
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-career-test.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'career_test_reports'; SHOW COLUMNS FROM career_test_reports;"
```

**永远不执行 `init.sql`**（线上已另存 `~/eggworld/backup/init.sql.READONLY-禁止执行`）。

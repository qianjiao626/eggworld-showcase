## 一、本次范围

本次为八卦大厅增加纯文字爆料区，并增加全站公告能力，解决用户缺少可审核爆料入口、奖励无法留痕以及主管理员无法向全站发布公告的问题。

- 普通用户发布的爆料进入审核；管理员可直接发布。
- 爆料支持匿名或实名展示，公开接口不泄露匿名发布者身份。
- 管理员审核、评论治理和奖励结算均受权限与状态约束，并记录操作留痕。
- 奖励金额限制为 `0..10000`，同一爆料只能结算一次，禁止给发布者本人操作结算。
- 标题、正文和评论在前端预检并由后端复验敏感词；第一版只支持文字，不支持图片和分类。
- 支持公开浏览、评论和点赞；已下架爆料不可继续评论或点赞。
- 只有 `USER.role === 'admin'` 的主管理员可以发布、编辑、下架公告；未登录用户和其他用户可查看已发布公告及发布者。

  - 新增 `announcements`、`announcement_actions` 两张表及索引。
  - 仅使用 `CREATE TABLE IF NOT EXISTS`，不修改存量数据，不执行 `DROP`、`TRUNCATE`。

### 3.2 上线前数据库备份

先在服务器执行以下命令，密码只在交互提示中输入，不写入命令历史、文档或仓库：

```bash
mkdir -p ~/eggworld/backup/db
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/eggworld_*.sql
ls -l ~/eggworld/backup/db/ | tail -3
```

确认最新 dump 属主为 `xiaos`、大小非 0，并使用 `head -1 ~/eggworld/backup/db/<本次 dump>` 确认文件可读；备份读不回来时暂停发布。

### 3.3 迁移顺序与确认

1. 备份数据库并确认备份可读。
2. 将两份 SQL 上传至 `/home/xiaos/eggworld/sql/`。
3. 在服务器使用交互密码执行：

```bash
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-gossip-reports.sql
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-announcements.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'gossip_reports'; SHOW TABLES LIKE 'gossip_report_comments'; SHOW TABLES LIKE 'gossip_report_likes'; SHOW TABLES LIKE 'gossip_report_rewards'; SHOW TABLES LIKE 'gossip_report_actions'; SHOW TABLES LIKE 'announcements'; SHOW TABLES LIKE 'announcement_actions';"
```

4. 确认全部新表存在后，再上传 jar 和前端文件并重启服务。永远不要执行 `/home/xiaos/eggworld/backup/init.sql.READONLY-禁止执行` 或任何 `init.sql`。

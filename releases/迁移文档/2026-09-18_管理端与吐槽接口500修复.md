## 一、本次范围

**修掉两个会让接口直接 500 的后端缺陷。** 两个都是「只在特定数据状态下才触发」的边界问题，本地全量接口巡检时发现。

### Bug 1：`GET /api/admin/user-activity` 500（用户活跃看板）

- **现象**：接口返回 500，后端日志 `Error instantiating interface com.eggworld.mapper.VisitorSessionMapper$HourlyActivity` / `NoSuchMethodException: ...HourlyActivity.<init>()`
- **根因**：`VisitorSessionMapper.HourlyActivity` 被声明成 **`interface`**。MyBatis 通过**无参构造反射**创建结果对象，interface 无法 `new` → 必然失败
- **修复**：改为 `class` + Lombok `@Data`（三个字段 `h` / `users` / `sessions` 不变，getter 名不变，SQL 与前端契约不受影响）
- **来源**：该缺陷由 `c1434b9`（管理员用户活跃看板）引入，**`main` 上同样存在**，非本次改动引入

### Bug 2：`GET /api/complaints/stats` 500（吐槽统计）

- **现象**：接口返回 500，日志 `Cannot invoke "java.util.Map.get(Object)" because the return value of "java.util.List.get(int)" is null`
- **根因**：`school_complaints` **空表**时 `AVG(score)` 返回 `NULL`，MyBatis 会把**整行**映射成 `null`（而不是 `{avgVal=null}`）；原代码直接 `avgRows.get(0).get("avgVal")` → NPE
- **修复**：先取行、再判空行与空值，均分回落 `BigDecimal.ZERO`
- **触发条件**：仅当吐槽表为空时触发（新库 / 清库后 / 线上尚无吐槽数据）

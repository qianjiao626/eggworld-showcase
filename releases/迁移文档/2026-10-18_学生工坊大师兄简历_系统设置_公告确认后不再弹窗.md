## 一、本次范围

一句话：把独立的「大师兄简历」站点以同域静态子站 `/rs/` 接入学生工坊，配套后端 AI 对标计费、草稿/历史记录与后台「系统设置」，同时让公告弹窗在用户确认后不再重复打扰。

1. **学生工坊新增「大师兄简历」入口**
   - 工坊卡片同标签跳转 `/rs/`，复用蛋蛋世界 `sessionStorage` 登录 token，简历站侧栏提供「返回蛋蛋世界」。
   - 简历站本身是 Next.js 静态导出（`output: export` + `basePath: /rs`），由 nginx 当普通静态文件服务，**没有独立进程、服务器不需要 Node**。
   - 功能：写简历、改简历（AI 深度对标）、历史对标、历史草稿、投递 tracker。

2. **后端新增简历能力（`/api/resume/*`）**
   - `GET /meta`：返回实际单价、标价、收费开关、每日次数、今日已用/剩余、当前蛋蛋币余额。
   - `POST /analyze`：DeepSeek 深度对标；按后台配置预扣蛋蛋币，AI 失败/落库失败全额退款；`requestId` 唯一键幂等，重复点击不重复扣费；每日次数按自然日统计成功记录。
   - `GET /analyses`、`GET /analyses/{id}`：历史对标列表与详情。
   - `POST /drafts`、`GET /drafts`、`GET /drafts/{id}`：结构化简历草稿。
   - 余额变动统一走 `PointService`（行锁 + `point_logs` 流水），不另建账本。

3. **后台「系统设置」（仅主管理员）**
   - 侧栏新增「系统设置」页，管理「大师兄简历 · 深度对标」的 `是否收费 / 单次价格 / 每人每天次数`。
   - 配置存 `app_settings` 表，业务侧每次请求实时读取，保存后立即生效、无需重启。
   - 默认**免费**（`resume.charge_enabled=0`），单价保留 50、每日 3 次，恢复收费时直接使用。

4. **公告弹窗确认后不再重复弹**
   - 点「我知道了」、右上角 ✕ 或「查看全部公告」都会记住当前最新公告（按用户隔离的 localStorage 锚点）。
   - 下次登录同一公告不再弹；只有管理员发布**更新的公告**才重新弹。已读圆点逻辑保持不变。

5. **本地开发与打包链路**
   - `start-frontend.cjs` 增加 `/rs/** → resume/out/**` 映射（本地点工坊卡片不再 404）。
   - `build-deploy.ps1` / `build-release.ps1` 检测到 `resume/` 变更时自动执行 `npm ci`（首次）与 `npm run build`，把 `resume/out/` 整包放进部署包 `frontend/rs/`。

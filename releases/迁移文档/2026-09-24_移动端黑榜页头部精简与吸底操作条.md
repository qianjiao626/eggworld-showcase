## 一、本次范围

**只改移动端（`@media(max-width:768px)` 内、且以 `#page-blacklist` 限定）的大学黑榜页版式：头部去掉两张极端卡、搜索框放到「蛋蛋吐槽墙」之上、三个操作按钮（大学PK / 参与吐槽 / 修改吐槽）吸附在页面底部；web 端（>768px）逐项比对无变化。**

起因：黑榜页手机端首屏被头部占满 —— 要先滚过「标题 + 副标题 + 统计 + 吐槽最狠 / 吐槽最少两张卡」，而搜索框和两个操作按钮又在吐槽墙下面，滚动后就点不到。需求方要求：去掉两张极端卡、搜索框上移到吐槽墙之上、三个入口随时可用。

- **头部精简**：`#page-blacklist .bl-extreme-card{display:none}`（「😈 吐槽最狠大学」「😇 吐槽最少大学」两张卡），头部网格改单列，只留标题 / 副标题 / 统计。
  DOM 与点击逻辑（`blWorstCard.onclick` / `blBestCard.onclick`，见 `growth-schoolv3.html` 内 `renderBlacklistStats`）保留不动，**web 端两张卡照常显示、照常可点**。
- **搜索框上移**：移动端 `.bl-toolbar{display:contents}` 把搜索框升为页面 flex 项，排到吐槽墙之前。新顺序：头部 → 搜索框 → 蛋蛋吐槽墙 → 分类 tab → 榜单
  （改前是 头部 → 吐槽墙 → 工具栏 → 分类 tab → 榜单，搜索框在墙下面）。搜索下拉仍相对搜索框定位（`position:absolute`），行为不变。
- **操作按钮吸底**：新增一层 `.bl-toolbar-actions` 包住「⚔️ 大学PK」「✍️ 参与吐槽」。web 端该层 `display:contents`（按钮仍是 `.bl-toolbar` 的 flex 子项，排版与加这层之前一致）；
  移动端变成 `position:fixed` 吸底条，`bottom:calc(68px + env(safe-area-inset-bottom))`（68px 与底部 4 格 tab 高度同源）、`z-index:40 < 底栏 50`，**不会遮挡底部 tab**。
  三个按钮等宽均分（`flex:1 1 0`）；「✏️ 修改吐槽」由外联 `js/complaint-edit.js` 注入到「参与吐槽」的父节点，因此自动落进吸底条 —— **本次一行 js 都没改**。
- **配套让位**：黑榜页激活时给 `.main` 补 52px 底部留白（避免榜单末条被吸底条压住）；右下角反馈悬浮球在本页上移到吸底条之上（改前会压住「修改吐槽」）。
  访客态（注册/登录浮卡固定在 `bottom:78px`）吸底条整体上移到浮卡之上，两者不重叠。
- 全部新规则都在 `@media(max-width:768px)` + `#page-blacklist` 限定内；未做 UA 判断、未写浏览器降级分支（`PROJECT_RULES.md` 2.7）。

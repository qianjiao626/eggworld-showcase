## 一、本次范围

为八卦页增加“中国大陆高校宿舍目录”，让用户可以搜索、浏览全量高校名单，并查看已录入的宿舍资料与通过审核的图片。学校展示名统一使用“蛋蛋世界的 + 真实校名”。登录用户可提交 JPG、PNG、WebP 宿舍图片，图片先进入待审核队列；审核权限独立于其他管理权限，由主管理员指定或撤销，驳回原因可填写也可留空。

本次上传限制统一为：单张不超过 **5 MB**、每次最多 **5 张**；Spring multipart 请求上限 **26 MB**；Nginx 仅对宿舍上传接口放宽到 **26 MB**，其他 API 仍为 **2 MB**。后端额外校验图片真实文件签名，不能只靠扩展名或请求 MIME。

## 三、数据库变更

新增脚本：`backend/sql/migrate-dormitory-directory.sql`，线上路径 `/home/xiaos/eggworld/sql/migrate-dormitory-directory.sql`。脚本只包含幂等 `CREATE TABLE IF NOT EXISTS` 与两条官方来源住宿费种子资料的幂等写入，不执行 `ALTER`、`DROP`、`TRUNCATE`，不修改余额、流水或既有任务数据。

新增三张表：

- `dormitory_profiles`：学校宿舍资料、来源 URL、来源年份、核实状态和备注。
- `dormitory_reviewers`：独立宿舍图片审核员授权；主管理员可指定或撤销。
- `dormitory_images`：图片 key、MIME、审核状态、审核员、驳回原因和时间。

上线获授权后按以下顺序执行，**先备份，再迁移，最后切 jar**：

1. 以普通用户 `xiaos` 执行库备份（密码仅在交互式提示输入，不写入文档）：

```bash
mkdir -p ~/eggworld/backup/db
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次 dump 文件>
```

备份文件必须属于 `xiaos`、大小非 0 且能够读回；读不回来就暂停发布。禁止使用 `sudo` 建目录或拷贝备份。

2. 上传迁移脚本到 `/home/xiaos/eggworld/sql/migrate-dormitory-directory.sql`，核对文件内容和哈希后执行：

```bash

mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'dormitory_%';"
```

3. 确认三张表均存在且应用用户可读写，再上传 jar 并重启服务。**本次 PR 阶段不执行以上任何线上命令。**

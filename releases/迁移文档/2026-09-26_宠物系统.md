## 一、本次范围

在「实验室.beta」新增 **宠物系统 v2.1（简化版）**：
- 玩法循环：赚蛋蛋币 → 商店买食物/玩具/道具 → 喂食/抚摸/玩耍/洗澡 → 8 维属性达标进化 → 图鉴收集。

- **所有扣币走后端**（`PointService`，type=spend），宠物与背包状态落库（换设备不丢）。

## 三、数据库变更

脚本：`backend/sql/migrate-pet.sql` → `/home/xiaos/eggworld/sql/migrate-pet.sql`。
内容：仅 `CREATE TABLE IF NOT EXISTS pets`（宠物：槽位/物种/阶段/闪光/属性 JSON/亲密度/饱食/心情/活力/清洁/时间戳）与 `pet_inventory`（背包：用户+物品唯一键）。**无 ALTER / DROP / TRUNCATE；不改存量数据、不动任何资金流水。** 可重复执行。

生产操作必须单独授权。普通用户 `xiaos`（**禁止 `sudo`**）先备份并验证可读：

```sh
mkdir -p ~/eggworld/backup/db
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次 dump 文件名>   # 能读出内容才算有效备份，读不回来就暂停
```

上传脚本后先比对 sha256，再仅执行一次；**先建表、再切 jar**：

```sh
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-pet.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'pets'; SHOW TABLES LIKE 'pet_inventory';"
```

**永远不执行 `init.sql`**。

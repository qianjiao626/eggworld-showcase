## 一、本次范围

**用户问题**：报名了任务，别人（发布者）驳回了我的报名，但侧栏「我的任务」的待处理红点一直不消失。

**根因**：`growth-schoolv3.html` 的 `taskStageOf()` 判定任务分组时，认领者侧只区分「是否已提交」：

```js
if(st === 'in_progress' || st === 'full'){
  if(isPublisher) return t.selectedClaimStatus === 'submitted' ? 'todo' : 'active';
  return t.myClaimStatus === 'submitted' ? 'active' : 'todo';   // ← rejected 落进 else
}
```

被驳回时 `myClaimStatus = rejected`，不满足 `submitted`，于是被归入 `todo`（待我处理），导致：

- 侧栏「我的任务」红点常驻
- 「待我处理」Tab 计数虚高
- 用户看到一条「已驳回」的卡片却出现在「待我处理」里，无法自行清除

**修复**：认领者侧增加 `rejected` 判断，归入已完成组。

```js
if(t.myClaimStatus === 'rejected') return 'done';
```

> 后端无需改动：`ClaimService` 已正确把落选者的认领置为 `rejected`，问题纯在前端分组判定。

## 三、数据库变更

执行 `/home/xiaos/eggworld/sql/migrate-cat-room.sql`：新建 `cat_reputation(user_id, score)`；旧版猫舍迁移若已执行，`cat_reward_grants` 唯一键由 `(season, room_id)` 升级为 `season`。尚未执行过原脚本时，本脚本创建所有猫舍表。**先检查每个赛季已有发奖记录数**：

```sql
SELECT season, COUNT(*) AS grants FROM cat_reward_grants GROUP BY season HAVING COUNT(*) > 1;
```

若有结果，暂停迁移并审计已发出的蛋蛋币与流水；**不要删除记录或反向冲正**。若 `cat_reward_grants` 还不存在，则跳过审计查询。先备份，再迁移，最后切 jar：

```sh
mkdir -p ~/eggworld/backup/db
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -lh ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次dump文件名>  # 可读、非空，否则暂停
mysql -u eggworld -p eggworld < /home/xiaos/eggworld/sql/migrate-cat-room.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'cat_reputation'; SHOW INDEX FROM cat_reward_grants;"
```

线上库账号仅 `eggworld`，密码交互输入；**禁止执行 `init.sql`**。本脚本不改存量用户口碑，也不会自动搬迁/修复先前误写的数据；若旧版猫舍曾上线，需单独审计互评口碑与历史奖励。

## 一、本次范围

管理员可在任务详情弹窗中将任意任务标记为「优质」，优质任务在广场列表中以紫色描边 + ⭐优质标签区别于普通任务，并自动排在同类型列表的前面。

- 后端：`tasks` 表新增 `featured` 列（TINYINT, 默认 0）；新增 `POST /api/admin/tasks/{id}/feature` 接口（切换 0↔1）
- 前端：广场卡片 `.featured-card` 紫色氛围 + `⭐ 优质` 标签；任务详情弹窗内管理员可见「标为优质 / 取消优质」按钮
- 广场排序：优质任务（featured=1）排在前面，同级内按发布时间倒序

## 三、数据库变更

**脚本**：`backend/sql/migrate-task-featured.sql` → `/home/xiaos/eggworld/sql/migrate-task-featured.sql`

**内容**：只有 ALTER TABLE ADD COLUMN（幂等：列已存在时跳过），无 DROP / TRUNCATE / 存量数据修改。

```sql
-- 新增 featured 列（TINYINT NOT NULL DEFAULT 0）
ALTER TABLE tasks ADD COLUMN featured TINYINT NOT NULL DEFAULT 0 COMMENT '优质标签 0=普通 1=优质';
```

**库备份命令**（在执行迁移前）：
```bash
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次 dump>
```

**顺序**：先在服务器执行建列，再切 jar。

**确认**：

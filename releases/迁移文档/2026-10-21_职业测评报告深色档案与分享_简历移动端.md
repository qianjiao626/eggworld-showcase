## 三、数据库变更

**① 脚本**：`backend/sql/migrate-career-share.sql` → `/home/xiaos/eggworld/sql/migrate-career-share.sql`

上传前如线上已有同名文件，先比对：

```bash
md5sum ~/eggworld/sql/migrate-career-share.sql   # 与本地一致才复用，否则覆盖上传
```

**② 内容**：

- `ALTER TABLE career_reports ADD COLUMN share_token VARCHAR(32) NULL`、`ADD COLUMN shared_at DATETIME NULL`
- `ADD UNIQUE KEY uk_career_reports_share (share_token)`
- 每步先查 `information_schema` 判断，可重复执行；不改存量数据、不修正历史资金
- 无 `DROP / TRUNCATE`

**③ 库备份（先备份再执行）**：

```bash
mkdir -p ~/eggworld/backup/db
mysqldump --single-transaction --default-character-set=utf8mb4 --set-charset \
  -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次 dump 文件名>    # 读得回内容才算有效备份，读不到就暂停发布
```

**④ 执行顺序**：备份 → 上传 SQL → 执行 → 再切 jar。命令：

```bash
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-career-share.sql
```

**⑤ 确认**：

```bash
mysql -u eggworld -p eggworld -e "SHOW COLUMNS FROM career_reports LIKE 'share%';"
mysql -u eggworld -p eggworld -e "SHOW INDEX FROM career_reports WHERE Key_name='uk_career_reports_share';"
```

预期：`share_token`、`shared_at` 两列存在；唯一键 `uk_career_reports_share` 的 `Non_unique=0`。

> ⚠️ 线上库账号是 `eggworld`，密码不写进文档、不落仓库，执行时交互输入。
> ⚠️ 永远不执行 `init.sql`：线上那份已另存为 `~/eggworld/backup/init.sql.READONLY-禁止执行`。

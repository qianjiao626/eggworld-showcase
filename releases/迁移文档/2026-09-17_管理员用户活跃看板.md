内容：

- `migrate-daily-active-stats.sql`：CREATE TABLE IF NOT EXISTS `daily_active_stats`
- 无 DROP / TRUNCATE / DELETE / ALTER 现有列
- 不改旧业务表结构、余额或流水
- **正式库迁移须单独授权。以下步骤本次未执行。**

普通用户 xiaos 备份，禁止 sudo 创建或复制备份：

```bash
set -e
mkdir -p ~/eggworld/backup/db
umask 077
dump=~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
mysqldump --single-transaction -u eggworld -p eggworld > "$dump"
chmod 600 "$dump"
test -s "$dump" && test -r "$dump"
ls -l "$dump"
head -1 "$dump"
# 非空、属主正确且能读回才继续。
sha256sum /home/xiaos/eggworld/sql/migrate-visitor-sessions.sql
sha256sum /home/xiaos/eggworld/sql/migrate-daily-active-stats.sql
# 与本地 Get-FileHash SHA256 结果一致后：
mysql --default-character-set=utf8mb4 -u eggworld -p eggworld < /home/xiaos/eggworld/sql/migrate-visitor-sessions.sql
mysql --default-character-set=utf8mb4 -u eggworld -p eggworld < /home/xiaos/eggworld/sql/migrate-daily-active-stats.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'visitor_sessions'; SHOW TABLES LIKE 'daily_active_stats'; SHOW COLUMNS FROM page_views WHERE Field IN ('session_id','visitor_id');"
```

顺序：**备份 → 上传 SQL 核验哈希 → 迁移 visitor_sessions（含 ALTER page_views）→ 迁移 daily_active_stats → 确认表和列 → 切新 jar**。密码仅交互输入。

**永远不执行 init.sql**；线上 `~/eggworld/backup/init.sql.READONLY-禁止执行` 不动。

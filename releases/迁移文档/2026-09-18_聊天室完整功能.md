## 三、数据库变更

新增 15 张表：

`chat_conversations`、`chat_conversation_members`、`chat_messages`、`chat_messages_archive`、`chat_read_states`、`chat_friend_requests`、`chat_friends`、`chat_follows`、`chat_blocks`、`chat_groups`、`chat_group_members`、`chat_mutes`、`chat_reports`、`chat_sensitive_words`、`chat_audit_logs`。

脚本只建表并写 4 个官方频道种子，不含 `USE`、`CREATE DATABASE`、`ALTER`、`DROP`、`TRUNCATE`，不改旧业务表，不更新余额/流水；敏感词由后台管理员维护，不在迁移中写入默认词。**永远不执行 `init.sql`。**

**备份命令（执行迁移前，普通用户 xiaos，禁止 sudo）：**

```bash
mkdir -p ~/eggworld/backup/db
mysqldump --single-transaction --default-character-set=utf8mb4 --set-charset \
  -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
head -1 ~/eggworld/backup/db/<本次dump>
```

**执行顺序：备份 → 上传 SQL → 执行 SQL → 确认 15 张表 → 切新 jar。**

```bash
mysql -u eggworld -p eggworld < /home/xiaos/eggworld/sql/migrate-chatroom.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'chat_%'; SELECT COUNT(*) FROM chat_conversations;"
```

## 三、数据库变更

**有变更。**

| 脚本 | 必做？ | 内容 |
|---|---|---|
| `migrate-dormitory-directory.sql` | ✅ **必须** | 幂等 `CREATE TABLE IF NOT EXISTS` ×3（`dormitory_profiles` / `dormitory_reviewers` / `dormitory_images`）+ 两条住宿费种子资料；不含 `ALTER` / `DROP` / `TRUNCATE`，不动余额与任务数据 |
| `migrate-dissolve-private-groups.sql` | ⭕ **可选** | 把存量私密群置为 `dissolved`；幂等、无 `DELETE`。**默认不执行**：不执行 = 只冻结（历史仍可查），执行 = 从会话列表消失（**不可逆**，需产品确认） |

执行顺序与命令（普通用户 `xiaos`，密码交互输入，**不写入任何文档**）：

```bash
# 1. 先备份（读不回来就暂停发布）
mkdir -p ~/eggworld/backup/db
mysqldump -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次 dump 文件>

# 2. 上传脚本到 ~/eggworld/sql/，核对内容后再执行（先建表）
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-dormitory-directory.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'dormitory_%';"     # 应返回 3 张表

# 3.（可选，需产品确认）解散存量私密群；脚本首条 SELECT 先看影响面
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-dissolve-private-groups.sql
```

- ⚠️ **顺序铁律**：先备份 → 再建表 → 最后切 jar。表先于代码，否则新接口一上线就报错。
- ⚠️ **永远不执行 `init.sql`**（含 `DROP TABLE`；线上那份已另存 `~/eggworld/backup/init.sql.READONLY-禁止执行`）。
- 若线上 `sql/` 已有同名脚本，先 `md5sum` 比对内容，避免执行到旧版。

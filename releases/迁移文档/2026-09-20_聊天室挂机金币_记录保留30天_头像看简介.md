## 一、本次范围

三项聊天室功能：

1. **挂机金币（泡点）**：在聊天室内停留即可获得蛋蛋币，规则按「方案 A」。
2. **聊天记录保留 30 天**：公共频道与私聊/群聊统一由 90/180 天改为 30 天（沿用既有「先归档再清热表」机制）。
3. **点头像看个人简介**：聊天室消息头像与会话头像可点击，复用主站用户名片弹窗。

### 挂机金币规则（方案 A）

| 规则项 | 设定 |
|---|---|
| 在线奖励 | 每在线 1 分钟 +0.5 蛋蛋币（实现为每 120 秒 +1 币，避免小数） |
| 每日在线金币上限 | **固定 20 币**（= 在线 40 分钟），与稀有度无关 |
| 发言加成 | 每条消息 +2 蛋蛋币，每日前 20 条有效（最多 +40，**不占用 20 币在线额度**） |
| 每日合计上限 | 20（在线）+ 40（发言）= **60 币** |
| 防挂机 | 两次心跳间隔超过 5 分钟（300 秒）的时段不计时；页面隐藏或超过 5 分钟无操作时前端停止上报 |

> 说明：用户确认「方案 A 全套，但每日在线额度改为 20 金币」（方案 B 口径）：**在线封顶 20，发言加成另算**，每日合计上限 60。数值全部为配置项（`online-cap-coins` 等），调整不需要改代码。
>
> ⚠️ 稀有度分档在 20 币量级下已无意义（20 币 = 在线 40 分钟，原 N 档 2 小时上限摸不到），故按用户确认取消分档。

## 三、数据库变更

**新增 1 张表**：`chat_online_reward`（聊天室在线奖励每日累计）。

- 脚本只 `CREATE TABLE IF NOT EXISTS`，不含 `USE` / `DROP` / `TRUNCATE` / `ALTER` / `DELETE`，不修改任何现有表。
- 字段：`user_id`、`reward_date`、`seconds`、`coins`、`msg_reward_count`、`last_tick_at`；唯一键 `uk_chat_online_user_date(user_id, reward_date)`；外键指向 `users(id)`。

**库备份命令（普通用户，禁 `sudo`）：**

```bash
mkdir -p ~/eggworld/backup/db
mysqldump --single-transaction --default-character-set=utf8mb4 --set-charset \
  -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
head -1 ~/eggworld/backup/db/<本次dump>
```

**执行顺序：备份 → 上传 SQL → 执行 SQL → 确认表存在 → 切新 jar。**

```bash
mysql -u eggworld -p eggworld < /home/xiaos/eggworld/sql/migrate-chat-online-reward.sql
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'chat_online_reward'; DESCRIBE chat_online_reward;"
```

> ⚠️ 线上库账号 `eggworld`，密码不写文档；**永远不执行 `init.sql`**。

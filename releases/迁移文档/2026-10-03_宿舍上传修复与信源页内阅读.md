## 一、本次范围

解决校园宿舍照片/文字投稿的重复提交、失败后草稿丢失、切换学校后旧请求覆盖新页面的问题，并让已有信源要点可在本站直接阅读。

- 图片/文字分别设置提交锁，提交期间禁用相应表单；校验文件数量、类型、大小及文字字段长度、来源 URL。
- 严格同时校验 HTTP 状态和 JSON 业务结果；宿舍文字提交不再经过会把非 JSON 包装成成功的共享 `apiPost`。401/403/413/429/500、非 JSON 与网络失败均不误报成功，不自动重试。
- 失败保留当前页面草稿，提示先查看提交记录再手动重试。401 清理过期 token 时比较请求 token，防止晚到响应清掉新登录态。
- 个人记录通过局部 fetch 读取，不修改全局登录态；无 token 不请求，旧 token 或旧读取代次的成功/失败/401 都不回填到新账号。新增 7 项回归先红后绿，覆盖完整 POST→记录刷新链及乱序读取。
- 请求快照与递增页面代次共同防止旧学校请求回填、误清新草稿，包含 A→B→A 切换；成功只清理仍与该次提交一致的字段/文件。
- 精确开放匿名 `GET /api/dormitories/notes`；仅公开已审核文字，上传、个人记录和审核接口仍需登录及既有权限。带 token 的封禁账号仍被拒绝。
- 北大、兰大现有历史查阅记录补充为页内要点段落，来源标题、年份、查阅日期可见，原站链接放在可选折叠区。非原站全文，未取得新证据的学校不补写来源正文。
- 不修改数据库结构、任务状态机、审核/奖励金额或资金规则；本轮不改 nginx、服务器和上传目录。

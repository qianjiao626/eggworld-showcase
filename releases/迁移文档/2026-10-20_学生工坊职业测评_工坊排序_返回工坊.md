## 一、本次范围

一句话：把「大师兄找方向」职业测评作为第二个工坊软件接入 `/rs/career/`，配套收费、报告记录与后台配置；同时让管理员能调整学生工坊卡片顺序，并统一工坊软件的「返回蛋蛋世界」落点。

- **收费**：默认 50 蛋蛋币/次、每人每天 3 次；后台可改是否收费 / 单价 / 次数；生成时预扣，失败全额退款，`requestId` 幂等；报告快照写入 `career_reports`。
- **后台系统设置**：新增「职业测评」收费卡与「学生工坊 · 入口排序」卡；仅主管理员可用。
- **学生工坊**：新增「大师兄找方向」卡片；管理员可上移/下移排序，`app_settings.workshop.order` 保存，学生下次进入生效。
- **返回工坊**：主站支持 `/#workshop` 深链；简历站、职业测评所有页面的「返回蛋蛋世界」统一回学生工坊，不再回首页。
- **简历体验修复**：「开始搞简历」直达「请选择岗位大类」，移除行业选择页；草稿列表移到岗位大类页；历史草稿/回填键按账号隔离。
- **界面修复**：测评答题页左上角新增「返回」、右上「我的报告」恢复可点击；图标字体就绪前隐藏，刷新不再闪 `arrow_back` 等英文。

## 三、数据库变更

**① 脚本**：`backend/sql/migrate-career-reports.sql` → `/home/xiaos/eggworld/sql/migrate-career-reports.sql`

上传前如线上已有同名文件，先比对：

```bash
md5sum ~/eggworld/sql/migrate-career-reports.sql   # 与本地一致才复用，否则覆盖上传
```

**② 内容**：

- `CREATE TABLE IF NOT EXISTS app_settings`（兜底，线上已存在则跳过）
- `CREATE TABLE IF NOT EXISTS career_reports`（id / user_id / answers_json / headline / report_html / cost / request_id / created_at，含 `uk_career_reports_request(user_id, request_id)` 幂等唯一键）
- `INSERT ... ON DUPLICATE KEY UPDATE setting_key=setting_key` 写入默认配置：`career.charge_enabled=1`、`career.analyze_cost=50`、`career.daily_limit=3`
- 无 `ALTER / DROP / TRUNCATE`，不改存量数据、不批量修正历史资金

**③ 库备份（先备份再执行）**：

```bash
mkdir -p ~/eggworld/backup/db
mysqldump --single-transaction --default-character-set=utf8mb4 --set-charset \
  -u eggworld -p eggworld > ~/eggworld/backup/db/eggworld_$(date +%Y%m%d_%H%M%S).sql
chmod 600 ~/eggworld/backup/db/*.sql
ls -l ~/eggworld/backup/db/ | tail -3
head -1 ~/eggworld/backup/db/<本次 dump 文件名>    # 读得回内容才算有效备份，读不到就暂停发布
```

**④ 执行顺序**：备份 → 上传 SQL → 执行建表/写默认配置 → 再切 jar。命令：

```bash
mysql -u eggworld -p eggworld < ~/eggworld/sql/migrate-career-reports.sql
```

**⑤ 确认**：

```bash
mysql -u eggworld -p eggworld -e "SHOW TABLES LIKE 'career_reports';"
mysql -u eggworld -p eggworld -e "SELECT setting_key, setting_value FROM app_settings WHERE setting_key LIKE 'career.%' ORDER BY setting_key;"
```

预期：`career_reports` 存在；三条 `career.*` 配置分别为 `1 / 50 / 3`。

> ⚠️ 线上库账号是 `eggworld`，密码不写进文档、不落仓库，执行时交互输入。
> ⚠️ 永远不执行 `init.sql`：线上那份已另存为 `~/eggworld/backup/init.sql.READONLY-禁止执行`。

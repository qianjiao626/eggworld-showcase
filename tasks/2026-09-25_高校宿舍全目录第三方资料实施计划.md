# 高校宿舍全目录与 200 字投稿实施计划

> **For agentic workers:** 逐项在本分支执行；每项按测试先行、实现、复测、提交闭环。对应 `tasks/2026-09-25_高校宿舍全目录第三方资料设计.md` 与用户补充的 200 字上限。

**Goal:** 2361 所学校的目录和空状态不失真，逐批展示可追溯的校方或第三方宿舍描述，直到 2321 个唯一校名逐校审计完成；文字投稿限制 200 字且继续审核。

**Architecture:** 沿用静态 `DORMITORY_FACTS` 作为逐校来源事实、原有 API 保存已审投稿。前端区分校方/第三方标签和缺资料状态；服务端限制长度，现有数据库字段保持兼容。采集台账记录真实进度，不批量虚构。

**Tech Stack:** 原生 JS、Node `node:test`、Spring Boot、JdbcTemplate、Maven。

## Global Constraints
- 网站目录为 2361 所，显示名称含「蛋蛋世界的」；目录全覆盖不等于资料全覆盖。
- 单一第三方事实可展示但标「第三方资料·待核实」，有来源、查阅日期和适用范围；未知字段写待核实。
- 原创封面不是实拍，无授权照片不转载；图片仍最多 5 张且每张 5 MB。
- 投稿文字 1–200 字，先审后发；不改表、不连线上库、不主动推送/PR/上线。

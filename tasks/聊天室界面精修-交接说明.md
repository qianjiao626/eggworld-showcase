> 关联：`tasks/导航合并与实验室入口.md`、`releases/迁移文档/2026-09-20_聊天室界面精修.md`

## 一、本次范围

在既有聊天室功能上做界面与交互精修，不改后端、数据库和业务规则：

- 会话列表：新增最后消息时间、未读角标与更清晰的空状态；会话项支持键盘进入。
- 消息区：按日期插入「今天 / 昨天 / 月日 星期」分隔；同一位发送者 3 分钟内的连续消息进行视觉分组。
- 输入区：新增字数计数（超过 900 字预警），发送成功、发送失败和切换会话时都保持同步。
- 消息操作：撤回按钮改为悬停 / 键盘聚焦显示，移动端常显。
- 滚动：新增「回到底部」按钮，仅在离开底部时出现。
- 无障碍：会话项 `role="button"` + `tabIndex=0` + Enter/Space 键进入；保留 `aria-label`。
- 样式：统一米白 / 深蓝 / 薄荷体系，动画只使用 `transform` / `opacity`，尊重 `prefers-reduced-motion`。

## 四、修复的缺陷

1. **重复函数定义**：`js/chatroom.js` 中 `timeText()` 与 `avatarText()` 各定义了两次，后定义覆盖前定义。
2. **输入计数器不同步**：发送成功、发送失败、切换会话后计数未刷新；已抽为 `syncComposer()` 统一同步。
3. **回到底部按钮被销毁**：按钮原本位于 `#chatroomMessages` 内部，而 `renderMessages()` 使用 `replaceChildren()` 清空该容器，渲染消息后按钮即消失。
4. **消息区不滚动**：桌面端消息容器没有受限高度，滚动发生在整个页面，导致「回到底部」永远不会触发；已改为 `.chatroom-shell` 定高、`.chatroom-messages` 内部滚动。
5. **空状态未居中**：`.chatroom-empty` 使用 `flex:1` 在非 flex 父容器下无效，已改为 `min-height:100%`。

以上均已修复，并新增契约测试覆盖 3、4 两项，防止回退。

> 说明：第 3、4 项是在补充截图时发现的；此前一轮验证脚本把 `jump:false` 误判为「按设计隐藏」，实为元素已被删除。此处更正。

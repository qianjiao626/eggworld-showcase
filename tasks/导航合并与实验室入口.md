## 一、做了什么

按「1C / 2A / 3 / 4A」执行：

1. **「我的任务」+「我的信息」合并为「我的」**：一个入口，页内顶部两个 Tab（我的任务 / 我的信息），默认落在「我的任务」。

3. **导航收敛**：
   - 桌面侧栏：… 大学黑榜 → **实验室.beta** → **我的**
   - 手机底栏：任务广场 / 吐槽·黑榜 / 发布 / **实验室** / **我的**
4. **顶栏快捷入口**：原「我的信息」按钮改为「我的」，跳转到合并页。
5. **未登录保护**：`mine` / `lab` / `publish` 需登录，未登录会引导注册。

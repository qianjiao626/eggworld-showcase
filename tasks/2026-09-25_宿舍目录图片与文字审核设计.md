# 宿舍目录图片覆盖、楼栋实拍与文字审核设计

> 2026-09-25 · 设计稿（待用户复核）
> 基线：Gitee `main` 合并提交 `4815b52`；线上 `/api/health` 版本 `2026-09-24_safe-http-url修复`。

## 目标与边界

1. 中国大陆高校目录沿用现有 2361 个校名及「蛋蛋世界的」展示前缀；全部学校页面都能看到**原创封面图**，封面必须明显标注「非宿舍实拍 / 暂无已核实宿舍实拍」，不能假装是宿舍建筑。
2. 尽量逐校检索官网及论坛照片和文字，优先官网；只有核实学校、校区、楼栋且有明确再使用许可或权利人授权的真实照片才下载到本站展示。每张来源照片保留来源页、作者、许可及所指楼栋证据。无许可只记录线索，不复制、盗链或伪造归属；无楼栋证据不放入精确楼栋实拍区。
3. 允许注册用户提交照片和文字。学校必填；校区、宿舍楼号推荐填写但可留空；未知楼号明确显示「未提供楼号」，不猜测。两类投稿都需指定审核员审核通过后公开，拒绝原因可选。
4. 全国资料采集按学校持续分批进行，记录逐校覆盖状态；「目录全覆盖」不等于「每校已有实拍」。不能把首批内容说成全国图片已完成。

## 方案选择

- **采用：动态原创封面 + 经许可的本站实拍 + 用户投稿审核。** 无图学校也有诚实的可视内容；资料来源、楼号、许可均可追溯。
- 不采用直接搬运官网/论坛全部照片：公开浏览不等于再发布许可，且楼栋对应关系难核实。
- 不采用只有外链的方案：无法满足用户希望照片在本站直接展示的要求。

## 页面与交互

- 列表仍可按学校搜索；学校卡片增加原创封面缩略图，详情页顶部显示原创封面。无已核实实拍时显示醒目的「暂无已核实宿舍实拍」；有合格实拍时在独立图片区展示，不将封面混入实拍数量。
- 详情页的照片按「校区 · 楼号」标记；缺项分别显示「校区未提供」「楼号未提供」。本站来源照片下显示可点的来源、作者和许可；用户照片标明「用户上传 · 已审核」。不展示房间号、居住者身份或上传者个人信息。
- 新增文字投稿区：学校由当前选中的目录项确定；用户填写内容（1–2000 字）、可选校区、可选楼号、可选来源 URL。来源 URL 只接受 HTTP(S)；所有文本按纯文本转义显示，不支持 HTML。成功提交后提示「待审核」，不会立即出现在公共详情。
- 文字「我的投稿」显示待审/通过/驳回及可选原因。审核页分开列待审照片、待审文字；沿用现有审核员指定/撤销机制。照片表单也增加可选校区、楼号，现有旧照片缺失元数据时兼容。

## 数据与接口

- 新增增量 SQL：`dormitory_notes`（学校、校区、楼号、正文、来源 URL、作者 ID、状态、审核人、可选驳回原因、时间）；`dormitory_images` 增加可空的校区、楼号。历史图片保持可读。不碰 `init.sql`，正式数据库迁移必须独立授权和先备份。
- 公共 `GET /api/dormitories?school=` 只返回已批准的文字和图片；分页/条数上限避免无界数据。现有照片 URL 与上传接口保留兼容。
- 新增 `POST /api/dormitories/notes`、`GET /api/dormitories/mine/notes`、`GET /api/dormitories/review/notes/pending`、`POST /api/dormitories/review/notes/{id}`。投稿需登录、审核需宿舍专属审核员；服务端限制长度/空白/协议，使用参数化 SQL，状态变更只能从 pending 执行一次。
- 首批合法来源实拍用静态素材及小型元数据清单随代码发布；不通过伪造用户审核记录进入上传表。素材、许可证据和归属逐项测试，后续学校分批扩充清单。动态原创 SVG 封面由前端生成，不需要存 2361 个文件。

## 验收与发布

- 2361 个校名均能打开并看到标注清晰的原创封面；有许可的实拍展示实际楼号、来源、作者、许可。图片加载失败不把破图充当实拍。
- 未登录投稿拒绝；文字/图片提交后公共查询不可见；只有指定审核员批准才可见；驳回状态对投稿者可见、原因可空；跨权限无法审核。文本/XSS、危险链接、大小与类型限制均有回归测试。
- 前端专项/全量、后端离线编译与相关测试通过；浏览器对空数据、有实拍、待审核及移动端布局验证。
- 代码、增量 SQL、素材及按模板填写的迁移文档同主题分支提交；等负责人说「提 PR」才推送与建 PR。PR 合并、正式数据库迁移、服务器上线、tag 均不由助手擅自操作。

## 分期与已知限制

- 第一批交付：封面全覆盖、用户文字审核与楼栋字段、已核实许可的少量样例实拍，以及待搜集学校清单/进度。全国 2361 校真实照片与文字为长期逐校核验任务，无法承诺全部有楼栋实拍。
- 论坛文字只整理可核实的事实及来源，不整段复制帖子；论坛图片没有明确再发布许可时保留来源线索，不导入本站。

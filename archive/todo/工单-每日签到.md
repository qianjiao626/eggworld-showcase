### 2.4 Service — `CheckinService.java`

**新建**: `backend/src/main/java/com/eggworld/service/CheckinService.java`

注入：`DailyCheckinMapper`, `UserMapper`, `PointService`

#### 方法 1: `checkin(Long userId) → CheckinVO`

`@Transactional` 事务内，严格按顺序：

1. `dailyCheckinMapper.selectCount` 查 user_id + check_date=today，count>0 → 抛 `BusinessException("今日已签到，明天再来吧！")`
2. `dailyCheckinMapper.insert` 写签到记录（唯一约束兜底防并发）
3. `userMapper.selectByIdForUpdate` 行锁读用户 → `user.setExp(user.getExp() + 5)` → `userMapper.updateById`
4. `pointService.changeBalance(userId, 5, "earn", "每日签到（+5 蛋蛋币 +5 经验）", null)`
5. 重新 `userMapper.selectById` 查最新数据 → 返回 `new CheckinVO(true, 5, 5, 最新exp, 最新points)`

> ⚠️ 注意：pointService.changeBalance 本身也是 @Transactional，嵌套调用会合并事务（默认 REQUIRED 传播）。

#### 方法 2: `getTodayStatus(Long userId) → CheckinVO`

无需事务，只读查询：

1. `dailyCheckinMapper.selectCount` 查今日是否有记录
2. `userMapper.selectById` 查当前 exp/points
3. 返回 CheckinVO（checked 由计数判断）

### 3.3 JS — 签到逻辑

#### 3.3.1 新增全局函数（放在 `<script>` 标签末尾 `</script>` 前）

```javascript
/* ===== 每日签到 ===== */

/** 页面加载 / 登录后调用：查询今日签到状态并更新按钮 */
async function refreshCheckinStatus() {
  var btn = document.getElementById('checkinBtn');
  if (!btn) return;
  // 仅登录学生可见
  if (!USER.registered || USER.isAdmin) {
    btn.style.display = 'none';
    return;
  }
  btn.style.display = 'flex';
  try {
    var res = await apiGet('/api/users/me/checkin/status');
    if (res.code === 200 && res.data) {
      if (res.data.checked) {
        btn.classList.add('checked');
        btn.querySelector('.checkin-icon').textContent = '✅';
        btn.querySelector('.checkin-text').textContent = '已签到';
        btn.title = '今日已签到，明天再来吧';
      } else {
        btn.classList.remove('checked');
        btn.querySelector('.checkin-icon').textContent = '📅';
        btn.querySelector('.checkin-text').textContent = '每日签到';
        btn.title = '签到领 +5经验 +5蛋蛋币';
      }
    }
  } catch(e) { /* 静默失败 */ }
}

/** 点击签到按钮 */
async function doCheckin() {
  var btn = document.getElementById('checkinBtn');
  if (!btn || btn.classList.contains('checked')) return;

  // 防连点
  btn.disabled = true;
  try {
    var res = await apiPost('/api/users/me/checkin', {});
    if (res.code === 200 && res.data) {
      // 更新按钮状态
      btn.classList.add('checked', 'pop');
      btn.querySelector('.checkin-icon').textContent = '✅';
      btn.querySelector('.checkin-text').textContent = '已签到';
      btn.title = '今日已签到，明天再来吧';
      setTimeout(function(){ btn.classList.remove('pop'); }, 400);

      // 更新全局经验/蛋蛋币
      USER.exp = res.data.totalExp;
      USER.points = res.data.totalPoints;
      refreshProfile(); // 刷新页面上的所有数字

      // Toast 提示
      showToast('🎉 签到成功！+5经验 +5蛋蛋币');
    } else {
      showToast(res.msg || '签到失败，请稍后再试');
    }
  } catch(e) {
    showToast('网络异常，签到失败');
  } finally {
    btn.disabled = false;
  }
}
```

function showToast(msg) {

  toast.style.cssText = 
    'position:fixed;top:20px;left:50%;transform:translateX(-50%);z-index:9999;' +

  setTimeout(function() {
    toast.style.opacity = '0';
    toast.style.transition = 'opacity .3s';
    setTimeout(function() { toast.remove(); }, 300);

}

## 五、关键注意事项

1. **时区**: `LocalDate.now()` 使用服务器时区，确保服务器时区为 Asia/Shanghai
2. **并发安全**: `check_date` + `user_id` 唯一约束是最后防线，前端防连点 + 服务端先查后插
3. **事务**: PointService.changeBalance 自带 @Transactional，外层 CheckinService.checkin 也加 @Transactional，Spring 默认 REQUIRED 传播会合并为一个事务
4. **样式兼容**: 侧边栏已有 compact 模式（`body.side-compact`），签到的 `.checkin-btn` 样式需同样适配 compact:
   ```css
   body.side-compact .checkin-btn { height: 32px; font-size: 12px; border-radius: 10px; }
   ```

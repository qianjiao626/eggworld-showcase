## 相对工单代码的必要补充

1. 使用 `LocalDate.now(ZoneId.of("Asia/Shanghai"))`，不依赖服务器默认时区。
2. 并发测试发现：先插签到再锁用户，会因外键共享锁与用户更新锁升级产生死锁。因此改为**先锁当前用户，再查询/插入签到，最后发奖励**。保留数据库唯一约束与重复键业务提示。
3. 补充跨零点计时、焦点刷新、旧账号响应隔离、移动端尺寸和顶部提示宽度，避免实际页面兼容性问题。
4. JS 状态初始化放在 USER 定义之后、首次页面初始化之前，避免末尾变量初始化覆盖早期登录/退出状态。
5. `init.sql` 同步新增表 DROP/CREATE，表数量说明更新为 19；**已有数据库不能执行此全量初始化脚本**。
